# UX Redesign Patch D — LLD Object Design Playground

## Included
- Adds an interactive object-design lab to the LLD home, between the LLD hero and roadmap.
- Four selectable example classes: Order, OrderItem, Payment, and InventoryService.
- Class responsibilities, attributes, operations, and relationship explanation update when a class is selected.
- UML and code views can be switched independently.
- Code examples follow the existing global Java/C++/Python language preference.
- Reset returns the playground to Order + UML without changing learning progress or preferences.

## Scope and limitations
- This is a conceptual teaching model, not a full UML editor or executable code environment.
- Existing roadmap, lesson progress, practice library, and language preference stores are unchanged.
- Responsive layout and reduced-motion preferences are included.

## Apply
Extract the ZIP at the project root and merge/replace the included files.
